# Depannage

## Le téléphone n'ouvre pas la page

- Vérifie que le téléphone et le PC sont sur le même Wi-Fi.
- Vérifie que Windows n'a pas bloqué l'application dans le pare-feu.
- Confirme que BouRemoteServ tourne toujours dans la zone de notification.

## Le contrôle de la souris ne bouge pas

- Actualise la page.
- Vérifie que l'application affiche toujours `Ready`.
- Assure-toi que le navigateur n'est pas passé hors ligne.

## Les touches media ne fonctionnent pas

- Certaines applications réagissent différemment aux touches media Windows.
- Réessaie après avoir redonné le focus à l'application cible.

## L'application ne démarre pas automatiquement

- Réactive le démarrage automatique depuis le panneau de réglages.
- Vérifie le réglage dans le menu de la zone de notification.
- Redémarre Windows une fois après avoir changé le réglage.
