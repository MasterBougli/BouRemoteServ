# Architecture

RemoteDock is split into two parts:

## Desktop app

- Starts a Windows tray icon
- Serves the local web interface
- Receives mouse and media commands
- Stores user preferences locally

## Mobile web UI

- Works in the phone browser
- Uses a premium dark theme
- Provides the mouse trackpad, d-pad, and media buttons
- Shows the local address and QR code for easy pairing

## Current limits

- One PC only
- Local network only
- No pairing code yet
- No volume or keyboard actions yet
