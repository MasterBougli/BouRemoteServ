# Uso

## Iniciar la aplicación

Abre BouRemoteServ en Windows. Se queda discreto en la bandeja del sistema y abre un panel web local para el teléfono.

## Conectarte desde el teléfono

Tienes dos opciones:

- Escanear el código QR que aparece en el panel
- Escribir manualmente la dirección local en el navegador del teléfono

## Controlar el PC

- Usa la gran zona táctil para mover el ratón
- Toca la zona táctil para hacer clic izquierdo
- Usa el pad direccional para ajustes precisos
- Usa los botones multimedia para `Play / Pause`, `Next` y `Previous`

## Buenas prácticas

- Mantén el teléfono y el PC en la misma red local
- Usa primero el código QR si la dirección es larga
- Deja la app de la bandeja abierta para que la conexión siga disponible

## Idioma

Puedes cambiar entre francés e inglés desde el panel de ajustes.

## Inicio automático

Activa o desactiva el inicio con Windows desde el mismo panel o desde el menú de la bandeja.
