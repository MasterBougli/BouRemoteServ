# Troubleshooting

## The phone cannot open the page

- Check that the phone and PC are on the same Wi-Fi network.
- Make sure Windows did not block the app in the firewall.
- Confirm the PC is still running RemoteDock in the tray.

## Mouse control is not moving

- Refresh the page.
- Verify that the app still shows `Ready`.
- Ensure the browser has not gone offline.

## Media keys do not work

- Some media apps respond differently to Windows media keys.
- Try the controls again after focusing the target app.

## The app does not start automatically

- Re-enable autostart from the settings panel.
- Check the tray menu toggle.
- Restart Windows once after changing the setting.
