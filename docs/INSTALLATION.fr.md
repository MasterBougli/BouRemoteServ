# Installation

## Prérequis

- Windows 10 ou Windows 11
- Python 3.12 ou plus récent pour le développement
- Un navigateur sur le téléphone, connecté au même Wi-Fi que le PC

## Installation pour le développement

1. Ouvre un terminal dans le dossier du projet.
2. Installe les dépendances :

```powershell
pip install -r requirements.txt
```

3. Lance l'application :

```powershell
python main.py
```

## Installation packagée

Utilise le script de packaging Windows dans `scripts/build_windows.ps1` pour créer un exécutable autonome.
