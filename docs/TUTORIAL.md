# Tutorial

## 1. Start the app on the PC

Launch `RemoteDock` on Windows. You should see it appear in the system tray.

## 2. Read the local address

Open the tray menu or the dashboard window. You will see a local address such as `http://192.168.x.x:8765`.

## 3. Open it on the phone

Use your phone browser to either:

- scan the QR code
- type the address manually

## 4. Move the mouse

Swipe on the large trackpad area to move the cursor.

## 5. Use media buttons

Tap:

- `Previous`
- `Play / Pause`
- `Next`

## 6. Change language

Use the language selector to switch between French and English.

## 7. Enable autostart if needed

Turn on the Windows startup switch if you want RemoteDock to launch automatically.
