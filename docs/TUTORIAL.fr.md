# Tutoriel

## 1. Démarrer l'application sur le PC

Lance `BouRemoteServ` sur Windows. Tu dois voir son icône dans la zone de notification.

## 2. Lire l'adresse locale

Ouvre le menu de la zone de notification ou la fenêtre du tableau de bord. Tu verras une adresse locale, par exemple `http://192.168.x.x:8765`.

## 3. Ouvrir depuis le téléphone

Avec le navigateur du téléphone, tu peux :

- scanner le QR code
- saisir l'adresse à la main

## 4. Bouger la souris

Glisse sur la grande zone tactile pour déplacer le curseur.

## 5. Utiliser les boutons media

Appuie sur :

- `Previous`
- `Play / Pause`
- `Next`

## 6. Changer la langue

Utilise le sélecteur de langue pour passer du francais à l'anglais.

## 7. Activer le démarrage automatique si besoin

Active le démarrage avec Windows si tu veux que BouRemoteServ se lance automatiquement.
