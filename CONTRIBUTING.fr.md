# Contribution

Merci d'aider à améliorer BouRemoteServ.

## Règles de base

- Garde le scope Windows pour le moment.
- Conserve le modèle local sur le réseau.
- Le téléphone doit rester sans installation.
- Préfère des changements simples et lisibles.

## Flux de travail

1. Fais une petite modification.
2. Lance l'application en local.
3. Vérifie que l'interface mobile fonctionne toujours sur petit écran.
4. Contrôle le menu de la zone de notification et les actions souris/media.
5. Mets la documentation à jour si le comportement change.

## Style de code

- Garde un Python lisible.
- Garde les textes utilisateurs bilingues quand c'est utile.
- N'ajoute pas de dépendance cloud.
