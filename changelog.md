# Changelog

## Unreleased

This project is still in its first public phase, so the changelog currently tracks the main feature set rather than numbered releases.

### Added

- Windows tray app with a local web control surface.
- Mouse trackpad control from the phone.
- Directional pad for precise pointer movement.
- Media controls for `Play / Pause`, `Next`, and `Previous`.
- QR-code and local-address onboarding.
- Bilingual interface support.
- Startup-with-Windows support.
- Dark premium UI polish.
- English, French, and Spanish documentation landing pages.

### Project state

- No tagged release has been published yet.
- The current work is intentionally minimal and focused on the core remote-control flow.
