# Contributing

Thanks for helping improve BouRemoteServ.

## Ground rules

- Keep the Windows-first scope for now.
- Preserve the local-network-only model.
- Keep the phone experience install-free.
- Prefer clear, minimal changes over broad rewrites.

## Development flow

1. Make a small change.
2. Run the app locally.
3. Verify the mobile UI still works at narrow widths.
4. Check the tray menu and the media/mouse actions.
5. Update docs if behavior changes.

## Code style

- Use readable Python.
- Keep UI text bilingual when it affects the user-facing surface.
- Avoid adding features that require cloud services.

## DCO

All contributions must include a DCO sign-off line in the commit message or pull request:

```text
Signed-off-by: Your Name <your.email@example.com>
```
