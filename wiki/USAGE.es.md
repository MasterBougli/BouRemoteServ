# Uso

## Iniciar la aplicación

Abre BouRemoteServ en Windows. Se queda en la bandeja y abre el panel local.

## Conectarte desde el teléfono

Tienes dos opciones:

- Escanear el código QR que aparece en el panel
- Escribir manualmente la dirección local en el navegador del teléfono

## Controlar el PC

- Desliza en la gran zona táctil para mover el ratón
- Toca la zona táctil para hacer clic izquierdo
- Usa el pad direccional para ajustes precisos
- Usa los botones multimedia para `Play / Pause`, `Next` y `Previous`

## Consejos rápidos

- Mantén los dos dispositivos en la misma red local
- Usa primero el código QR si la dirección es larga
- Deja la app abierta para conservar el acceso desde el teléfono
