# Utilisation

## Démarrer l'application

Lance BouRemoteServ sur Windows. L'application reste dans la zone de notification et ouvre le tableau de bord local.

## Se connecter depuis le téléphone

Tu as deux options :

- scanner le QR code affiché dans le tableau de bord
- saisir l'adresse locale à la main dans le navigateur du téléphone

## Contrôler le PC

- Utilise la grande zone tactile pour bouger la souris
- Tape sur le pavé tactile pour un clic gauche
- Utilise le pavé directionnel pour les petits réglages
- Utilise les boutons media pour `Play / Pause`, `Next` et `Previous`

## Conseils rapides

- Garde les deux appareils sur le même réseau local
- Utilise d'abord le QR code si l'adresse est longue
- Laisse l'application ouverte pour garder l'accès au téléphone
