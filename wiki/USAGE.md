# Usage

## Start the app

Launch BouRemoteServ on Windows. It stays in the tray and opens the local dashboard.

## Connect from the phone

You can connect in two ways:

- Scan the QR code shown in the dashboard
- Enter the local address manually in the phone browser

## Control the PC

- Swipe on the large trackpad to move the mouse
- Tap the trackpad for a left click
- Use the directional pad for precise nudges
- Use the media buttons for `Play / Pause`, `Next`, and `Previous`

## Quick tips

- Keep both devices on the same local network
- Use the QR code first if the address is long
- Leave the tray app open while using the phone remote
