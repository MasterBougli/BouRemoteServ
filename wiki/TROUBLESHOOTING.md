# Troubleshooting

## The phone cannot connect

- Check that the PC and phone are on the same Wi-Fi network
- Make sure BouRemoteServ is still running in the tray
- Refresh the dashboard to get the current local address

## The page does not open

- Try the QR code again
- Try the manual local address shown in the dashboard
- Confirm that Windows Firewall is allowing the app

## Mouse movement feels too fast or too slow

- Use shorter swipes on the trackpad
- Move the finger more slowly for precise control

## Media buttons do nothing

- Make sure the active Windows app supports the media key action
- Try another foreground app to confirm playback control works
