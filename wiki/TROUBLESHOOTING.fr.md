# Depannage

## Le téléphone ne se connecte pas

- Vérifie que le PC et le téléphone sont sur le même Wi-Fi
- Vérifie que BouRemoteServ tourne toujours dans la zone de notification
- Rafraîchis le tableau de bord pour récupérer l'adresse locale actuelle

## La page ne s'ouvre pas

- Réessaie avec le QR code
- Réessaie avec l'adresse locale affichée dans le tableau de bord
- Vérifie que le pare-feu Windows autorise l'application

## La souris va trop vite ou trop lentement

- Fais des gestes plus courts sur le pavé tactile
- Déplace le doigt plus lentement pour plus de précision

## Les boutons media ne réagissent pas

- Vérifie que l'application Windows active supporte la commande media
- Teste avec une autre application au premier plan pour confirmer le contrôle
