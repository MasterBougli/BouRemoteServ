# Security

RemoteDock is designed for a trusted local network.

## Current model

- No cloud account is required.
- No data is sent outside the local PC and phone connection.
- The interface is intended for use on a private Wi-Fi network only.

## Good practice

- Use it only on a trusted home or office Wi-Fi network.
- Do not expose the local port to the public internet.
- Keep Windows firewall rules limited to the local network.

## Planned improvements

- Optional PIN pairing
- Device authorization
- Better access logging
