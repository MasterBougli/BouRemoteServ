# Sécurité

BouRemoteServ est conçu pour un réseau local de confiance.

## Modèle actuel

- Aucun compte cloud n'est nécessaire
- Rien n'est envoyé en dehors du PC et du téléphone sur le réseau local
- L'interface est prévue pour un Wi-Fi privé seulement

## Bonnes pratiques

- Utilise-le uniquement sur un Wi-Fi de maison ou de bureau de confiance
- N'expose pas le port local à Internet
- Garde les règles du pare-feu Windows limitées au réseau local

## Améliorations prévues

- PIN de jumelage optionnel
- Autorisation d'appareil
- Meilleur journal d'accès
