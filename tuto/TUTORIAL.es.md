# Tutorial de BouRemoteServ

## 1. Inicia la app en el PC

Abre BouRemoteServ en Windows. Debes verlo en la bandeja del sistema.

## 2. Lee la dirección local

Abre el menú de la bandeja o la ventana del panel. Verás una dirección local como `http://192.168.x.x:8765`.

## 3. Ábrela en el teléfono

Usa el navegador del teléfono para:

- escanear el código QR
- escribir la dirección manualmente

## 4. Mueve el ratón

Desliza en la gran zona táctil para mover el cursor.

## 5. Usa los botones multimedia

Pulsa:

- `Previous`
- `Play / Pause`
- `Next`

## 6. Cambia el idioma

Usa el selector de idioma para cambiar entre francés e inglés.

## 7. Activa el inicio automático si lo necesitas

Activa el inicio con Windows si quieres que BouRemoteServ se abra automáticamente.
