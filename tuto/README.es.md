# Tutorial de BouRemoteServ

**Idioma:** [English](README.md) | [Français](README.fr.md) | [Español](README.es.md)

Usa esta carpeta cuando quieras una guía paso a paso en lugar de una página de referencia.

## Lo que incluye

- Un inicio guiado y tranquilo
- Un flujo claro para conectarte desde el teléfono
- Una introducción rápida al ratón y a los botones multimedia
- Ajustes de idioma y arranque automático al final

## Orden recomendado

1. Abre el tutorial en tu idioma.
2. Sigue la parte de conexión desde el teléfono.
3. Prueba el ratón y los controles multimedia.
4. Termina con el idioma y el arranque automático.
